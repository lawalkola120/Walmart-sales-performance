# Walmart Sales performance

## Tools used  
- Microsoft Excel
- Power Query
- Date function

## Project Overview
This project analyzes the monthly and yearly sales performance for walmart stores.
It explores trends, profit margiss, and customer behaviour using pivot tables and interactive dashboards.

## What i learned
- How to clean messy Excel data using formulas
- How to summarize KPIs using pivot tables
- How to use power query
